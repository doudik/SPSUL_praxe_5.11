# Extrakce inzerátů bytů - Evaluační nástroj

- **Projekt:** Měření kvality a ceny LLM modelů při strukturované extrakci dat z inzerátů nemovitostí do JSON.
- **Jazyk:** Python 3 (knihovny: requests, python-dotenv).
- **Úloha:** 3. Inzeráty bytů (dispozice, plocha_m2, cena_kc, mesto).
- **Struktura:**
  - `data/dev.jsonl` (15 případů)
  - `data/test.jsonl` (10 případů)
  - `prompts/v1.txt`, `prompts/v2.txt`
  - `src/eval.py`
  - `results/summary.json`
